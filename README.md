## Hi, I'm Hector 👋

**Backend developer** expanding into **Data Science & Machine Learning**.

[![CV site](https://img.shields.io/badge/CV%20site-miCVsite-2ea44f?style=for-the-badge&logo=github)](https://hmangam78.github.io/miCVsite/)
[![LinkedIn](https://img.shields.io/badge/LinkedIn-0A66C2?style=for-the-badge&logo=linkedin&logoColor=white)](https://www.linkedin.com/in/hector-gamiz/)

I'm a backend developer from Málaga who recently completed the **Common Core at 42 Málaga Fundación Telefónica**, a project-based school where I built systems from scratch: Unix system programming, concurrent networking, and full-stack applications in C, C++, Python, and TypeScript.

One of my favourite projects was **Transcendence**, a 3D multiplayer RPG where each player's character is generated from real data of the 42 intranet — turning students' academic progress into in-game attributes. Building it meant designing REST APIs, handling concurrent sessions, and integrating external services into a data-driven experience.

### 🧠 Currently learning

I'm deepening my foundations in **Data Science & Machine Learning** with Python. I'm deliberately learning the fundamentals the hard way — data extraction, manipulation, and processing — by building projects from scratch instead of letting AI write the code for me. I also keep exploring **Generative AI and LLM integrations** for backend systems.
